02 / GET STARTED

Install it where you work.

Choose a full plugin install for Codex or Claude Code, or copy the standalone skill into another agent.

Run this in a terminal, restart the desktop app, then open Plugins → NITI plugins → Extensive Prompt Architect → Install.
codex plugin marketplace add Ext7/extensive-prompt-architect

This adds a community GitHub source; the plugin is installed in the app. It does not appear in OpenAI’s official public directory.
