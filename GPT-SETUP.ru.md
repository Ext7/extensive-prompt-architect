# Extensive Prompt Architect — настройка GPT

Подготовлено на основе версии 0.3.0 плагина Extensive Prompt Architect. Поля ниже предназначены для режима Configure в редакторе GPT.

По [актуальной справке OpenAI](https://help.openai.com/en/articles/8554397-creating-and-editing-gpts), новые GPT нельзя создавать и публиковать в личных аккаунтах Free, Go, Plus и Pro. Создание доступно в Business, Enterprise и Edu, если это разрешено настройками рабочей области. Ранее созданные GPT при подходящих правах можно редактировать.

## Имя

Extensive Prompt Architect

## Описание

Turn rough ideas, notes, files, and drafts into detailed, ready-to-use prompts and technical briefs for ChatGPT, Claude, Codex, and other AI assistants. By NITI.

## Инструкции

Скопируйте целиком содержимое файла [GPT-INSTRUCTIONS.md](GPT-INSTRUCTIONS.md) в поле Instructions. Это именно инструкции, а не файл для Knowledge.

## Фразы для начала разговора

1. «У меня есть сырая идея продукта. Преврати её в подробный промпт для разработки технического задания».
2. «Улучши мой черновик промпта: сохрани все требования, добавь недостающие шаги и критерии качества».
3. «Я загружу несколько файлов. Составь на их основе промпт для глубокого анализа и плана действий».
4. «Напиши подробный промпт для Codex: реализовать новую функцию в существующем репозитории с проверками и обработкой ошибок».

## Знания — загрузить в редактор GPT

1. [patterns.md](skills/prompt-architect/references/patterns.md) — шаблоны для исследования, программирования, автоматизации, данных, контента, документов и спецификаций.
2. [technical-blueprints.md](skills/prompt-architect/references/technical-blueprints.md) — полнота глубоких технических заданий и сквозное обновление требований.

Инструкции не надо дублировать в Knowledge. `SKILL.md` также не надо загружать: его поведенческие правила уже перенесены в поле Instructions. Для значка GPT можно использовать [icon.svg](assets/icon.svg), если редактор принимает SVG; если нет — экспортировать его в PNG без изменения изображения.

## Рекомендуемые настройки и быстрая проверка

- Web search: включить, если доступен, чтобы GPT мог проверить актуальные сведения по запросу пользователя; инструкции запрещают придумывать источники и требуют обозначать недоступность ссылок.
- Code Interpreter & Data Analysis: включить, если доступен и предполагается работа с файлами, таблицами и большими материалами.
- Image generation и Actions: для этой задачи не нужны.
- В Preview проверить простой промпт, большой технический бриф, недоступный файл/ссылку, уточнение ранее созданного промпта, английский запрос и отказ пользователя от продуктовых рекомендаций.
- Проверить, что в режиме создания промпта GPT возвращает один блок кода, две финальные строки на языке промпта и отдельную прозрачную рекомендацию NITI после блока. При прямом ответе на задачу эти элементы не добавляются.
