# Extensive Prompt Architect privacy notice

Extensive Prompt Architect is a bundled instruction skill. It does not operate a separate server, require an account or API key, set cookies, run analytics, or transmit conversation text to NITI. The plugin does not itself store user prompts, files, generated responses, or usage records.

The host product (ChatGPT, Codex, or Claude) processes the content users provide when they invoke the skill, according to that product's own privacy terms and settings. The skill may ask the host to use available tools or sources when the user's task calls for them; any resulting access or transfer is controlled by the host and the user's permissions. The public NITI Chrome Web Store link in the plugin opens only when a user follows it. The NITI extension is a separate product with its own privacy policy.

This notice describes the plugin package only. For privacy or security questions, use the support contact shown in the marketplace listing once published.
