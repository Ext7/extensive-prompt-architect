# Security Policy

## Supported versions

Security fixes are provided for the latest published release. If the project
has no published releases, use the current `main` branch.

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue. Use GitHub's
**Report a vulnerability** option on this repository when it is available. If
private vulnerability reporting is unavailable, contact the repository owner
through their GitHub profile and include only the information needed to
reproduce the issue.

This project provides local prompt and skill files. It does not run a hosted
service, collect telemetry, or require credentials. Reports about unsafe
instructions, installer behavior, or unexpected file changes are in scope.
