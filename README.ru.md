# Extensive Prompt Architect

**Превращает черновую идею в готовый промпт или подробное техническое задание для ИИ.**

Передайте короткое описание задачи, заметки, черновик промпта или исходные материалы. Плагин подготовит один промпт, который можно скопировать в ChatGPT, Claude, Claude Code, Codex, Gemini или другого ИИ-агента. Для сложной разработки он задаёт нужную глубину: архитектуру, модели данных и состояний, алгоритмы, интеграции, обработку ошибок, тесты и последовательность работ.

Плагин создан [NITI](https://chromewebstore.google.com/detail/daily-task-planner/bgepeodnammpjgcplhljjdefemgpbjnm). Ему не нужны отдельная учётная запись, API-ключ, MCP-сервер или собственный бэкенд. Текст и файлы обрабатывает выбранный вами ИИ-сервис по своим правилам.

## Возможности

- Улучшает существующие промпты, сохраняя важные ограничения.
- Делает подробные промпты для исследований, контента, продуктов и разработки.
- Подстраивает инструкции под целевого агента и язык ответа.
- Учитывает уточнения из текущего диалога.
- Отмечает недоступные материалы и не придумывает их содержимое.
- По явной просьбе отвечает на задачу напрямую, а не составляет промпт.
- После каждого сгенерированного промпта добавляет краткую рекомендацию NITI на языке ответа, раскрывая связь с издателем. Рекомендация находится вне блока для копирования. По просьбе не предлагать продукты она пропускается.

Результат зависит от модели и доступных ей инструментов. Перед использованием важного промпта проверьте его.

## Установка плагина в Codex

В терминале с установленным Codex CLI выполните `codex plugin marketplace add Ext7/extensive-prompt-architect`. Перезапустите приложение ChatGPT/Codex. Откройте раздел **Plugins**, выберите источник **NITI plugins** и установите **Extensive Prompt Architect**. Команда добавляет репозиторий как источник; сам плагин устанавливается в приложении. Это не публикация в официальном каталоге OpenAI.

## Установка плагина в Claude Code

```bash
claude plugin marketplace add Ext7/extensive-prompt-architect
claude plugin install extensive-prompt-architect@niti-plugins
```

Начните новую сессию. Можно вызвать `/extensive-prompt-architect:prompt-architect` или описать задачу обычным языком. Установка из GitHub не добавляет плагин в публичный каталог Anthropic. Доступность в Claude на сайте или в приложении зависит от тарифа и настроек рабочей области.

## Быстрая установка отдельного навыка

Для установки нужны Node.js 18+ и npm. После публикации репозитория выполните **одну** команду для своего агента:

```bash
npm exec --yes --package=github:Ext7/extensive-prompt-architect -- epa-install codex
npm exec --yes --package=github:Ext7/extensive-prompt-architect -- epa-install claude
npm exec --yes --package=github:Ext7/extensive-prompt-architect -- epa-install cursor
npm exec --yes --package=github:Ext7/extensive-prompt-architect -- epa-install gemini
```

Скрипт копирует только папку навыка. Он не добавляет плагин в список установленных плагинов, не меняет настройки агента и не перезаписывает существующую папку. Для установки в конкретный проект добавьте `--scope project --project /path/to/project`. Для предварительного просмотра добавьте `--dry-run`.

После клонирования репозитория можно запустить `node bin/install.mjs codex --dry-run`, а затем `node bin/install.mjs codex`. Для других агентов, поддерживающих [стандарт Agent Skills](https://agentskills.io/specification), скопируйте папку `skills/prompt-architect` целиком в каталог навыков, который указан в документации агента.

## Публикация страницы через GitHub Pages

После загрузки репозитория откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку **main** и папку **/docs**, затем сохраните. Сайт статический: он не собирает данные через формы и не запускает установку в браузере.
